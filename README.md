MeeMeals is a passion project that I developed to help users get organized with their meals. I have a lot of future plans for application but currently users can create meals, schedule their meals, and view the current week schedule of meals!

View MeeMeals [here](http://meemeals.com) **Disclaimer, website is no longer hosted on AWS**

The technologies used are React, NodeJS, MongoDB, Nginx, redis, Typescript, and AWS/EC2

## To run the application follow these steps

### Services

Run Docker Services
`docker compose down -v --remove-orphans docker compose up`

Rebuild
docker compose down -v --remove-orphans
docker compose up --build
